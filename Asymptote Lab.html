Rules

Write the function as a top over a bottom. Let n be the degree of the top and m the degree of the bottom.

  1. Factor the top and the bottom.
  2. Cancel common factors. Each one is a hole.
  3. Set what is left of the bottom to 0. Each solution is a vertical asymptote.
  4. Compare n and m for the horizontal or slant asymptote.
Hole

A factor that cancels from top and bottom. Set it to 0 to get x, then put that x into the simplified function to get y.

Vertical asymptote

A factor that stays in the bottom after cancelling. Set it to 0. The graph climbs or drops without bound beside this line.

Slant asymptote

Exists when n = m + 1. Divide the top by the bottom. The quotient, without the remainder, is the line.

Horizontal asymptote rules

Compare degreesHorizontal asymptoteExample
n < m y = 0 (3x + 1)/(x² + 1)
n = m y = leading coefficient of top ÷ leading coefficient of bottom 3x²/(x² + 1) gives y = 3
n > m None. If n = m + 1, use a slant asymptote instead. (x² + 3x + 2)/(x − 1)

Only the highest powers matter for this rule. Cancelling a common factor lowers n and m by the same amount, so the answer is the same before and after.

A graph can cross its horizontal asymptote in the middle. It only has to level off toward the far left and far right. The first example above crosses y = 0 at x = −1/3.
